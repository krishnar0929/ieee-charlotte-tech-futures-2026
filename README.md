# IEEE Tech Futures 2026 — Embodied, Physical AI

Static one-page event landing page for the September 12, 2026 event at EPIC — UNC Charlotte.

## Preview locally
Open `index.html` in a browser.

## Registration
The Register buttons point to the official IEEE vTools event page:
https://events.vtools.ieee.org/m/567969

## Deploy
This folder can be deployed directly to Netlify, Cloudflare Pages, GitHub Pages, or any static web host.

## Files
- `index.html` — page structure/content
- `styles.css` — styling and responsive layout
- `script.js` — live countdown
- `assets/physical-ai-event.jpeg` — provided event flyer
